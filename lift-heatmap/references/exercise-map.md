# Exercise to muscle map

Main muscle = 1 effective set per set. Helper = 0.5. If an exercise is not listed, choose the closest one and say so.

Keys: quads, hams, glutes (glute max), glutemed, adductors, calves, shins, lats, midback, traps, lowback, delt_r (rear delt), pecs, abs, obliques, delt_f (front delt), delt_s (side delt), biceps, triceps, forearms.
